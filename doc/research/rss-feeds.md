# LuminaFeed — Curated RSS Feed Research (G0.R)

> Generated **2026-09-21**. Canonical machine-readable copy: [`rss-feeds.json`](./rss-feeds.json) — the G0.7 seeder reads that file directly. This Markdown is the human-readable companion and is kept in sync with the JSON.

## Purpose

Deliverable for **G0.R** in the [master plan](../plans/00-master-plan.md): a curated seed list of public RSS feeds, the category set they imply (replacing the spec's illustrative list), and a **fixed popularity figure** per feed for the public feed list's default ordering. IDs are GUID v7 generated by the seeder, so feeds reference their category **by name**.

## Methodology

- **Sourced** well-known publisher RSS/Atom endpoints across ten categories.
- **Live-validated** every URL (browser user agent): kept only feeds returning **HTTP 200** with a body that parses as RSS/Atom/RDF and contains **at least one item**.
- Captured whether each response advertises **ETag** and/or **Last-Modified** (relevant to polling C4 conditional-GET / 304 handling) and whether sample items carry an image enclosure.
- Resolved a **feed image**: RSS channel image / Atom logo, else the site's scraped **og:image**, else null (cards render without one — the spec allows "if available").
- **popularity** is a fixed integer (higher = more popular), assigned from rough real-world prominence and made globally unique so the default sort is deterministic. The absolute scale is arbitrary; only ordering is used.
- Feeds returning non-200, HTML instead of a feed, or blocking automated requests (403/406/429/202) were dropped.
